# PlutoNotebooks
Notebooks with [Pluto](https://plutojl.org/)

---- 

Folder `scalarizingFunction` (stable; used of teaching):
- the weighted Tchebychev scalarizing function
- the augmented weighted Tchebychev scalarizing function

It shows, for a static sample of points $y \in Y$ representing the outcome set for a bi-objective problem, the points selected using one of the two scalarizing function.

---- 

Folder `Astar` (stable):
- select one situation (two maps are available)
- select randomly a departure and an arrival
- compute the path with $A^*$ algorithm

It shows, for a given map, the best path from a departure D point and an arrival A point. 

---- 

Folder `PathFinding`(stable; used of teaching):
- select one algorithm among (1) Breadth-First-Search, (2) Dijkstra, (3) Greedy-BFS, (4) A*
- select the condition among (1) normal, (2) sand, (3) sand+water
- select the departure and arrival among (1) static, (2) dynamic
- display graphically the result and values

Presentation introducing the PathFinding (principle, application, algorithms, illustration) and the project to do. 

----

Folder `PlanarParallelRobot5R` (stable; simple illustration):
- two sliders allow to move the robot
- trace the points accessed by the robot and the singularity positions

Basic animation showing the points accessed by planar parallel 5R robot and the singularity positions

---- 

Folder `AutonomousMobileRobotics` (stable; simple illustration):
- 5 statics paths of robots are given
- display the move of robots, identify and display the collisions

Basic animation showing the moves of robots on a map and display collisions
